# Desk teaching (`teaching/`)

File-based loop for the [teaching plugin](https://github.com/cursor/plugins/tree/main/teaching): `create-learning-path` and `run-learning-retrospective`.

**Not** Chart bot weights. **Not** a PnL scoreboard. **No secrets.**

| File | Job |
| --- | --- |
| [PROGRESS.md](./PROGRESS.md) | Current milestone + next checkpoint (one owner) |
| [SESSION-LOG.md](./SESSION-LOG.md) | One row per completed phase |
| [RETRO.template.md](./RETRO.template.md) | Copy to `YYYY-MM-DD-session-N.md` |
| Dated sessions | What was practiced, score, DARK list, next move |

Plan: [docs/LEARNING-PATH.md](../docs/LEARNING-PATH.md). Chart bot retros stay in [`ta-learning/`](../ta-learning/). Grok **core later**: [docs/CORE-FIT.md](../docs/CORE-FIT.md) (helix-cx PR #1). Teaching PASS ≠ CX LIVE.
